# Legacy reference

This directory is outside the active MATLAB path.

- `code_20260826.zip` is a dated snapshot of the earlier package-based
  implementation. It is kept only for provenance and emergency comparison;
  do not run it as the current code.
- Older `Code-DensityFormulation/` scripts are no longer assumed to exist at
  a relative path. The active implementation is entirely contained in the
  project root documented by `../README.md`.

Do not copy routines from the archive back into `+src/` without comparing
the mathematical interfaces and running the full test suite.
